# 脱敏响应样本

`team-roster.response.sample.json` 是根据用户提供的球队名单响应正文裁剪出的样本。它保留响应分组、24 名球员的 `person_id` 与 `person_name`、主教练的 `person_id` 与 `person_name`、成员类型和赛季链接，用来演示结构校验和离线导入；年龄、图片链接、薪资等非必要字段没有保存。导入时会把前锋、中场、后卫、门将分组标题写入 `players.attr`，并只把教练分组中 `type` 为 `主教练` 的一人作为一条人员记录写入，`attr` 为 `主教练`。`team_players` 仅保存人员与球队的关联。其他教练组成员和工作人员不会导入。

`team-schedule.response.sample.json` 保留用户提供的赛程响应，包括 127 项赛季选项、52 场当前赛季比赛及顶层 `list` 字段，用于验证 `current` 赛季选择、字段清洗、按 `match_id` 去重和离线导入。该样本对应懂球帝球队 ID `50000529`，当前赛季为 `2026/2027`。比赛中的队徽链接、比赛链接、比分和状态均按响应字段保留；它不包含认证凭证。

导入赛程样本时还要传入用户提供的赛程 URL 作为 `--request-url`。导入器会将它与响应中唯一当前赛季的 URL 和 `name` 对照，确保响应中的比赛确实对应最新赛季。

`roster-import` 每次处理一份新名单时，都会用响应中的姓名和位置/岗位更新 `players` 表，并替换 `team_players` 中该球队的人员关联。接口实时请求尚未实现；当前命令读取的是本地响应文件。

该文件只有响应正文，不包含原始 HTTP 方法、请求头、HTTP 状态码或认证上下文。`seasons[].url` 是响应内容，不能单独作为本次实际请求的证据。后续添加真实抓包时，先移除 Cookie、Token、账号标识和非必要个人信息，再更新接口契约。

赛程样本也只有响应正文，不包含 HTTP 状态、请求头或认证上下文。响应中 `season_list[].url` 是服务端提供的当前赛季链接，只用于校验目标球队和赛季参数，不证明请求认证方式。
